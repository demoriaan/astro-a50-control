A50 Control

Set up your ASTRO A50 in the browser

Equalizer, microphone, stream mix and base station – straight over USB, nothing to install. You hear changes immediately; “Save” stores them on the headset.

Try without a headset

What you need

  • A Chromium-based desktop browser such as Chrome, Edge or Opera – on Windows, macOS, Linux or ChromeOS. Firefox and Safari do not support WebHID.
  • The A50 base station (Gen 4) connected to your computer via USB.
  • No other program talking to the base station at the same time: close the A50 Control desktop app, ASTRO Command Center or G HUB first.
  • On Linux, a one-time udev rule so the browser may access the device: 
    echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="9886", ATTRS{idProduct}=="002c", MODE="0660", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-astro-a50.rules
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw

Drag the points to change gain and frequency. The mouse wheel over a point changes the bandwidth of bands 2 to 4.

Unofficial tool, not affiliated with ASTRO Gaming or Logitech. ASTRO and A50 only name the compatible device. This page sends no data over the network; it only talks to your base station via WebHID.
